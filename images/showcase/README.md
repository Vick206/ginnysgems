# Studio photographs

The public cards and viewer use `catalog.js` as their shared source. Each stone has `{stone-id}-600.jpg` and `{stone-id}-1200.jpg`, at a 4:3 ratio. These are subject-centered crops of the six supplied email photographs, re-encoded without copying source EXIF metadata. Color and inclusions have not been retouched. Originals remain in ignored TemporaryResources/.

IDs: peridot-001, garnet-red-001, ruby-studio-001, cz-001, garnet-ghana-001 and sunstone-001. The studio ruby deliberately uses a new ID so the former demo ruby-001 URL cannot silently refer to a different stone. Photo identifications remain provisional in catalog metadata and the public introduction. Confirm identities before removing that note.

Update the shared catalog when replacing a photo; do not edit archived sample cards. Keep matching filenames and alt text in sync. Weights and dimensions remain null until verified. The six original demo filenames are retired and must not be used for the new stones.
